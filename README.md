# WATERSHIELD

Winter Operations Monitoring and Decision Support course prototype.

Open `WATERSHIELD.sln` in Visual Studio with the .NET desktop development workload and .NET 8 SDK. Build the solution to check your setup. The WPF project starts with a blank window.

| Project or folder | Purpose |
| --- | --- |
| `Watershield.App` | WPF application shell |
| `Watershield.Core` | Shared contracts and core logic |
| `Watershield.Devices` | Device folders with Sprint 1 assignments |
| `Watershield.DeviceTests` | Test project shell with folders for each teammate |
| `data/scenarios` | Placeholders for light snow, heavy snow, and freezing rain data |

Create a branch from `main` and add your work to your own folders. Agree on the shared contracts, CSV formats, and test framework as a team. The GitHub workflow checks that the solution builds.
